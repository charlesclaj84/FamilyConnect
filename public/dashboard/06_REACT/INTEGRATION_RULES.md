# Claude Integration Rules

1. Inspect the existing BO repository before choosing implementation technology.
2. Preserve the current framework, router, API contracts, authorization, data model, forms, and business logic.
3. Do not add Tailwind, a new icon library, a new state library, or a component framework solely for this redesign.
4. Treat the supplied SVG files as production assets, not inspiration.
5. Use the official Golden Master PNG as the visual regression reference at 1536×1024.
6. Keep photographic media raster; use the exact SVG clipping paths for their shapes.
7. For responsive layouts, preserve hierarchy and curve language rather than scaling the desktop page down mechanically.
