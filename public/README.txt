GENORRA - Premium Family Identity v1.0

Brand name: GENORRA
Acronym: Generations Embracing Nurturing Our Roots, Relationships & Ancestry
Values lockup: Connect • Plan • Celebrate
Lead brand line: Where every generation belongs.

PACKAGE CONTENTS
- SVG_Masters: vendor-ready SVGs with text converted to outlines.
- Editable_SVG: grouped SVGs with live text for design edits.
- PNG_Exports: 1024, 2048, 4096 and 8192 px exports for primary, horizontal and mark variants.
- App_Icons: light/dark SVGs plus common platform PNG sizes.
- Favicons: favicon.svg, PNG sizes and multi-resolution favicon.ico.
- Web: CSS custom properties and JSON design tokens.
- Brand: brand guide, color guide, typography guide and a production preview board.
