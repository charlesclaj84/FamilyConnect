- sidebar / layered curves

### Photography
The Golden Master uses real family photographs. These remain JPG media and are clipped by vector masks. Converting photos into vector polygons would reduce visual fidelity and create unusable implementation assets, so the package does **not** cartoonize or auto-trace people.
